# Radiation monitor simulator

This very simple web page simulates a radiation monitor, with ionizing radiation level from base ambiental values (0.001 µSv/h) to extreme values (1 Sv/h).

## Controls

- Radiation intensity: from 0.001 µSv/h to 1 Sv/h
- Randomness: percent value of how much the count value differs from the intensity
- Volume: defines the sound volume of the clicks
